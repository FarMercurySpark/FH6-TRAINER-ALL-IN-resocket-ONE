# Forza Horizon 6 Trainer All-in-One

**Forza Horizon 6 Trainer All-in-One** is the current **FH6 trainer** for Windows: **forza horizon 6 money** freeze, unlock all cars, speed boost, teleport, god mode, instant win and XP multiplier. Insert opens ImGui. Built for FH6 v1.640 (August 2026).

## What's new in v3.2 (August 31, 2026)
- Offsets for FH6 v1.640.112.0
- Wheelspins toggle
- Faster auto-attach (~1s)
- No-damage covers DLC cars again
- Money freeze holds after festival reset
- Garage unlock list refresh (812+ cars)

## Key Features
- Credits locked at 999,999,999 (F1)
- All 812+ cars (F4)
- Speed 1x-10x (F2)
- No damage (F3)
- Teleport to waypoint (F5)
- Instant win (F6)
- Skip checkpoint (F7)
- XP 5x / 10x / 100x (F8)
- Steam / Microsoft Store / Xbox App

## Getting Started
1. Download v3.2.
2. Launch Forza Horizon 6, then `FH6Trainer.exe` as Administrator.
3. Press Insert, toggle with F1-F8.

## FAQ

**Online?**
Offline / solo only. Online sessions can get you banned.

**After a patch?**
Wait for a trainer update if offsets move.

**Microsoft Store build?**
Yes. Steam, Microsoft Store and Xbox App attach the same way.
